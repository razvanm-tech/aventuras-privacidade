# Aventuras na Matemática — privacy policy

The privacy policy and support page for the iOS app **Aventuras na Matemática**, in Portuguese,
English and Romanian.

Published at <https://razvanm-tech.github.io/aventuras-privacidade/> and given to Apple as the
app's Privacy Policy URL and Support URL.

This repository is public only so that GitHub Pages can serve the page. The app's source code
lives elsewhere and is private.
